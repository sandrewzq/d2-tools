# 玩家使用指南

这份文档面向普通玩家，按真实使用顺序说明 d2-tools 怎么安装、登录和日常使用。

## 1. 安装与启动

1. 下载 Windows x64 安装器 `d2-tools-setup-<version>.exe`。
2. 运行安装器，选择安装位置。
3. 安装完成后启动 d2-tools。

d2-tools 不需要你手动安装 Node.js、Python 或 Docker。

## 2. 数据目录与升级

默认数据目录：

```text
%APPDATA%\d2-tools
```

这里会保存：

- Bungie 配置
- OAuth token
- 资料库缓存
- 仓库标签和备注
- DIM 愿望单导入
- 操作日志和诊断数据

安装或更新程序时，这些数据不会被自动删除。

如果你以前用的是旧项目名 `d2-service`，首次运行 d2-tools 时会自动把旧目录复制到新目录。程序不会自动删掉旧目录。

## 3. 首次启动

首次打开时，你会先进入引导或配置状态。你至少需要完成两件事：

1. 填写 Bungie 配置
2. 登录 Bungie

更详细的 Bungie Application 创建步骤见 [Bungie 配置指南](bungie-setup.md)。

## 4. 登录 Bungie

填好 `API Key`、`Client ID` 和 `Client Secret` 后：

1. 点击“登录 Bungie”
2. 浏览器会打开 Bungie 授权页
3. 登录并授权
4. 浏览器回跳后，软件会保存 token

如果授权完成后软件仍然没有进入首页，先看 [常见问题](faq.md) 里的登录章节。

## 5. 初始化资料库

登录完成后，点击“初始化资料库”。

这一步会下载 Destiny 2 资料库，用于：

- 中文装备名搜索
- perk 搜索
- 来源摘要
- 资料库页查询

资料库可以重复更新，不会影响你的 Bungie 配置和本地标签。

## 6. 首页：今日 / 本周

首页主要用来快速看：

- 每日重置
- 每周重置
- 今日行动建议
- 本周重点
- 已接入并且可确认的数据来源状态

这里的原则很简单：只显示 Bungie API 或本地资料库能确认的内容。拿不准的数据会明确显示为空或未接入，不靠猜。

## 7. 账号页

账号页会自动读取当前 Bungie 账号数据，主要包括：

- 角色 tab 切换
- 当前光等
- 当前装备
- 角色背包
- 邮政官
- 材料与消耗品摘要

你可以在这里做两类常用操作：

- 保存当前装备为本地方案
- 一键装备最高光等

“装备最高光等”会优先从当前角色、角色背包和仓库里找更高光等的装备，执行前会确认，不会直接分解装备。

## 8. 仓库页

仓库页是 d2-tools 目前最接近 DIM 日常使用体验的部分。

你可以在这里：

- 按武器、护甲、装备、其他查看仓库
- 按位置、弹药、护甲属性、锁定状态、本地标签筛选
- 给装备加本地标签：保留 / 关注 / 可清理
- 写本地备注
- 查看同名装备对比
- 复制清理清单
- 用清理模式把目标装备解锁并转移到角色背包

### 8.1 同名对比

“同名对比”模式适合处理：

- 同一把武器有多件不同 roll
- 同名装备分散在不同位置
- 想快速决定哪件留、哪件标成可清理

你可以：

- 选中一件作为基准
- 选择其余候选
- 选择可清理候选
- 直接点”保留这件，其余关注”
- 直接点”保留这件，其余可清理”

### 8.2 清理模式

清理模式不会直接分解装备。它只帮助你：

- 批量解锁
- 批量转移到角色背包
- 生成更容易在游戏里核对的定位信息

最终分解仍然需要你进入游戏手动完成。

### 8.3 社区推荐数据

装备详情和仓库匹配可以读取三类本地推荐来源：

- DIM Wishlist
- 应用推荐（本地社区推荐表）
- 用户明确确认后保存的“我的推荐”

本地社区推荐表需要你手动导入。d2-tools 不默认内置未授权的社区表格数据。
在装备 AI 分析中输入的新知识默认只对本次分析生效；只有在保存确认框中明确确认后，才会写入“我的推荐”。详情推荐和 AI 上下文不会为此自动读取社区网页。

JSON 格式示例：

```json
{
  "title": "中文社区推荐",
  "rules": [
    {
      "item_hash": 123,
      "perk_hashes": [11, 22],
      "mode": "pve",
      "note": "清怪组合",
      "source_label": "本地社区表"
    }
  ]
}
```

CSV 格式示例：

```csv
title:中文社区推荐
item_hash,perk_hashes,mode,note,source_label
123,"11,22",pve,清怪组合,本地社区表
456,33|44,pvp,对战组合,本地社区表
```

字段说明：

- `item_hash`：武器 hash。
- `perk_hashes`：推荐 perk hash 列表，JSON 用数组，CSV 可用逗号、竖线、分号或加号分隔。
- `mode`：`pve`、`pvp` 或 `general`。
- `note`：这组推荐的简短说明。
- `source_label`：详情页显示的来源名称；不填时显示“本地社区表”。

## 9. 资料库页

资料库页用于查资料，不直接读取你的仓库内容。

你可以：

- 搜索装备中文名
- 搜索装备英文名
- 搜索 perk
- 保存常用别名
- 看来源、基础说明和 perk 关联信息

它更像“本地 Destiny 资料查询”，不是仓库页的替代品。

## 10. 小日向 Bot

小日向 Bot 用来处理攻略和配装说明。粘贴文本后，按顺序使用“解析攻略”“对照账号”“生成草稿”“保存草稿”。

- 解析攻略：把职业、子职业、异域、武器、perk、属性和模组拆成结构化要求。
- 对照账号：只根据当前账号、仓库、目标规则、资料库和已导入推荐判断，不猜测未接入数据。
- 生成草稿：把已拥有装备生成可保存配装草稿，把缺口保留为清单。
- 保存草稿：写入本地方案；装备、转移或游戏内写操作仍需要你在界面里确认。

如果某个要求无法确认，小日向会放进“待确认”，不会当成事实。

## 11. AI 助手

AI 助手采用聊天框方式，而不是固定报告按钮。

它可以基于你当前已载入的数据回答问题，例如：

- 这周我优先该刷什么
- 我仓库里哪些装备疑似重复
- 哪些武器适合先保留
- 我现在最值得整理的部分是什么

支持的模型接口：

- OpenAI Responses
- OpenAI Chat Completions
- Anthropic Messages

如果没配置 AI，页面会提示你先去设置页完成配置。

## 12. 设置页

设置页主要管理：

- Bungie 配置
- AI 配置
- 本地数据目录状态
- 写操作开关
- 操作日志与诊断信息

如果你只是浏览账号和仓库，不需要开启写操作。

## 13. 写操作边界

写操作包括：

- 锁定 / 解锁
- 装备到角色
- 从仓库取出到角色
- 从角色移入仓库
- 一键装备最高光等

写操作默认关闭。即使开启，也仍然需要 Bungie Scope 和确认流程。

d2-tools 不支持直接分解装备。

## 14. 常见日常流程

### 14.1 初次跑起来

1. 配置 Bungie
2. 登录 Bungie
3. 初始化资料库
4. 自动读取账号
5. 进入仓库页开始整理

### 14.2 清理仓库

1. 进入仓库页
2. 用同名对比查看重复组
3. 保留一件，其他标成关注或可清理
4. 进入清理模式
5. 批量解锁并转移到角色背包
6. 进游戏按清单手动分解

### 14.3 冲最高光等

1. 进入账号页
2. 选择角色
3. 点击“装备最高光等”
4. 确认操作

### 14.4 让 AI 帮你分析

1. 先在设置页完成 AI 配置
2. 读取账号和仓库数据
3. 打开 AI 助手
4. 直接输入你的问题
