### 详细条目

**Bug #5 · 遗失区域数据为空（P1）**

根因（2026-06-24）：代码调用 Bungie 公共里程碑 API `/Destiny2/Milestones/`，该端点返回日落/试炼/铁旗等全局活动，不包含每日遗失区域。检测算法没问题，数据源本身就是错的。

备选方案：
1. **角色级 Profile API**（推荐，最准）：`GET /Destiny2/{membershipType}/Profile/{membershipId}/?components=202,204`，需 OAuth
2. **静态 Manifest 推算**（兜底）：从 `DestinyActivityDefinition` 筛选 lost sector 类型，用轮换规则推算今日图
3. **两者结合**：有登录用方案 1，未登录用方案 2

### P1 · AI 抄作业与自动配装方案生成

> **目标** 粘贴攻略或配装资料后，AI 解析装备/星象/属性/模组/武器/异域要求，对照账号数据给出可执行配装方案和缺口清单。

**要做什么**
- 设计攻略输入结构：纯文本、链接摘要、配装说明、手动补充条件
- 设计 AI 解析输出 schema：职业、子职业、星象/碎片、异域、武器、模组、属性目标
- 设计账号匹配逻辑：已拥有、缺失、可替代、属性不足、需升级、需刷取
- 设计方案生成结果：推荐组合、替代方案、缺口清单、刷取建议、操作步骤
- 与现有配装模板、仓库目标规则、装备详情联动

**会议结论** AI 辅助"抄作业"：解析攻略 → 对照账号 → 生成可操作方案，不只是文字建议。

**验收** 粘贴攻略后 AI 能结构化列出要求；对照账号给出匹配度和缺口；输出至少一个可保存配装草稿。
