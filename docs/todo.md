- 当前活动能力更偏“能拉到记录”，离玩家真正想看的“最近打了什么、和谁打的、打得怎么样”还有距离。
- 缺少把原始活动记录整理成可回顾、可比较、可扫描摘要的展示层。

任务：

- 按 Raid / Dungeon / 常规活动分组最近记录。
- 增加队伍成员、完成时间、失败 / 完成状态、关键统计的可读摘要。
- 提供“最近 10 场活动”快速复盘视图。

预期结果：

- 用户打开后，不用逐条读原始记录，也能快速回忆最近活动情况。

### P4 · 桌面发布体验闭环

目标：

- 从绿色包可用，逐步走向正式桌面软件体验。

当前问题：

- 目前更偏“能运行的绿色包”，但从普通用户角度看，安装、更新、备份、恢复和问题诊断还没有形成完整闭环。
- 功能本身和“可长期使用的软件体验”之间还有一段产品化收尾工作。

任务：

- 维护开发期和发布期两条独立链路：开发期使用 `npx pnpm@9.15.0 dev:desktop` 或 `scripts/dev-desktop.ps1` 热启动桌面应用，发布前再走绿色包打包验证。
- 评估自动更新方案。
- 评估安装包方案。
- 增加本地备份 / 恢复向导。
- 评估托盘图标是否真的符合使用场景。
- 梳理 `%APPDATA%/d2-tools` 数据目录迁移、备份和诊断导出的用户说明。

预期结果：

- 让用户即使不懂开发环境，也能更安心地安装、升级、迁移和排查问题。

## 暂不优先

### 装备模板 / 本地配装模板使用引导（原 `Bug #3`）

- 当前问题：已有配装相关能力，但用户不容易理解“模板”“当前装备”“本地保存方案”之间的区别，也不知道入口和推荐使用顺序。
- 后续目标：补清晰的引导、空状态说明和典型使用场景，降低第一次使用门槛。

### 完整 TWID 级日报 / 周报聚合（原 `Bug #7`）

- 当前问题：当前“今日 / 本周”更偏结构化接口数据展示，还不是接近 TWID / 中文日报机器人的完整聚合视图。
- 后续目标：补更多轮换、活动提示、重点摘要和分享文本，让它更像玩家每天愿意看的摘要页。

### DIM 整理工具文案与交互边界重命名（原 `Bug #9`）

- 当前问题：当前“整理”“清理”“候选”“建议保留”这些词在语义边界上还不够稳，容易让用户误解为工具会直接执行高风险写操作。
- 后续目标：把文案改得更接近“分析建议 / 候选清单 / 人工确认执行”，减少误解和心理负担。

### 完整 DIM 级拖拽式装备移动

- 当前问题：当前已有写操作和装备转移基础能力，但还没有 DIM 那种高自由度、低摩擦的拖拽移动体验。
- 后续目标：支持更直观的角色/仓库间拖拽、批量移动和冲突反馈。

### 完整护甲属性优化器

- 当前问题：目前能看单件护甲属性、基础评分和筛选条件，但还没有真正的“整套护甲搭配求解器”。
- 后续目标：支持按职业、属性目标、模组约束和异域装备组合计算更优配装方案。

### Destiny Tracker 级排行榜

- 当前问题：当前活动和账号数据还没有形成可比较、可排序的战绩排行榜视图。
- 后续目标：补玩家常见的 PVP / PVE 统计排行、关键指标对比和阶段性表现趋势。

### Raid Report 级完整副本复盘

- 当前问题：当前活动复盘仍偏基础记录展示，离 Raid Report 那种副本履历、通关细节和队伍表现分析还有明显差距。
- 后续目标：补齐副本级记录、历史趋势、关键节点和队伍协作视图。

### 默认内置未授权社区表格数据

- 当前问题：社区推荐能力已经在扩展，但默认内置第三方社区表格会带来授权、维护和过期风险。
- 当前结论：在明确授权前，不内置任何未授权社区数据，只保留导入能力和本地使用链路。

### 公网服务、多用户共享链接、图片化报告发布

- 当前问题：这些能力会把本地单机工具扩展成带发布、分享、托管属性的产品，复杂度和安全边界会陡增。
- 当前结论：现阶段继续坚持“本地优先、单用户、自主授权”，暂不扩展到公网服务和分享分发场景。
