## 优先开发

### P0：每日 / 每周面板增强

目标：让首页每日信息从“能显示数据”变成“玩家每天愿意看”。

任务：

- 强化 `packages/core/src/daily/liveData.ts` 的商人售卖解析，优先覆盖老九、枪匠、艾达、圣人、拉乎尔等常用商人。
- 为商人条目增加“售卖物品名 + 类型/稀有度/关键属性”的展示格式。
- 改进遗失区域识别逻辑，补充英文、中文、活动名和 quest 名的兜底匹配。
- 将每日/每周面板整理为“今日必看 / 本周轮换 / 商人库存 / 数据来源状态”。
- 保持原则：只显示 Bungie API 或本地 Manifest 能确认的数据，不猜测未确认内容。

验收：

- `packages/core/test/daily.liveData.test.ts` 覆盖商人售卖和遗失区域解析。
- `packages/desktop/test/daily-panel-items.test.ts` 或新增测试覆盖 UI 文案。
- 首页面板在无数据、部分数据、完整数据三种状态下都有清晰反馈。

### P1：护甲属性与同名对比重做

目标：仓库整理时不再只看一个总分，而是让玩家看到“为什么这件值得留或删”。

任务：

- 在账号物品摘要中稳定暴露护甲六维属性。
- 仓库筛选支持按护甲属性数值区间过滤和排序。
- 同名对比区分武器与护甲：武器看 perk 差异、社区推荐命中、wishlist 命中；护甲看属性差异、总值和关键属性组合。
- 重新设计评分解释：展示评分来源、命中规则、扣分原因。
- 先做“属性可见 + 可筛选 + 可对比”，不要一开始就做完整优化器。

验收：

- 单件装备详情能显示已拥有护甲属性数值。
- 仓库能按关键属性筛选护甲。
- 同名对比不再只依赖总分。
