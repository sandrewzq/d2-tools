# d2-service 路线图

更新时间：2026-06-19

这份路线图用于跟踪 d2-service 的功能状态。README 面向普通玩家，这里更偏开发和发布规划。

## 当前定位

d2-service 的主入口是 Windows 图形客户端。普通玩家下载绿色包后，解压、双击即可使用，不需要 AstrBot、Hermes、Docker、NAS 或中心服务器。

长期架构保持三层：

```text
Windows GUI
  ↓
d2-service core
  ↓
Bungie API / Manifest / 本地数据
```

core 能力优先服务 GUI，同时保留本机 HTTP API 和 MCP server 的扩展方向。HTTP/MCP 是高级接口，不是普通玩家入口。

## 0.0.3 目标

0.0.3 不再只做“仓库和写操作候选版”，而是作为第一版公开测试基线：

```text
0.0.3 = 仓库整理 + 今日面板 + AI 分析 + 安全写操作 + 工具协议骨架
```

0.0.3 的原则：

- 能从 Bungie API 或本地 Manifest 拿到的真实数据才展示。
- 数据源不可靠时显示“暂不可用/待接入”，不猜测。
- AI 只做分析和建议，不直接读取 secret/token，不自动执行写操作。
- 写操作必须经过本地开关和用户确认。
- 绿色包升级不覆盖用户配置、OAuth token、Manifest 缓存、仓库标签、备注和日志。

## 0.0.3 已纳入能力

### 基础和发布

- Windows Electron + React 图形客户端。
- Windows x64 绿色包。
- 首次启动配置引导。
- 配置页可重新打开，支持修改 Bungie 和 AI 配置。
- GitHub tag 自动构建 `.7z` Release 包。
- 本地数据目录保存用户配置、token、缓存、标签、备注和日志。

### Bungie 和 Manifest

- Bungie OAuth 登录。
- 本地 HTTPS callback。
- OAuth token 本地保存和自动刷新。
- Manifest 初始化、本地缓存、中文资料读取。
- 物品搜索、perk 搜索、图标、描述、来源摘要。
- 常用别名和中英混合搜索基础能力。

### 账号和仓库

- 账号页读取 Bungie 账号、角色、光等、当前装备。
- 当前装备和角色背包按 Destiny 位置分组展示。
- 一键最高光等：从当前角色已装备、角色背包和仓库中选择最高光等武器/护甲，执行前二次确认。
- 消耗品/材料数量展示。
- 仓库完整列表。
- 仓库主分类、位置分段、位置筛选、弹药筛选、搜索、排序、锁定筛选、标签筛选、评分筛选。
- 弹药类型来自 Bungie Manifest `equippingBlock.ammoType`，用于主弹/特殊/重弹筛选。
- 高级搜索语法：`tag:keep`、`tag:junk`、`locked:true`、`locked:false`、`type:weapon`、`type:armor`、`score>=75`。
- 仓库标签：保留、关注、可清理、清除。
- 本地备注。
- 清理清单复制。

### DIM 式整理能力

- 本地仓库评分。
- 可清理/复查/保留建议。
- 同名装备和同 Hash 装备分组。
- 同名 roll 对比。
- 重复装备建议。
- 愿望单 MVP：基于本地 perk 规则提示疑似好 roll，不依赖外部社区数据。
- 整理模式：批量选择当前结果、可清理、复查、未标记、有备注。
- 批量标记和批量清除。
- 清理模式：批量解锁、转移到角色背包，最终分解仍需进游戏手动完成。
- 仓库和清理操作按钮有等待文案、禁用态和忙碌态提示。

### 小日向式今日面板

- 首页今日/本周摘要。
- 每日重置和每周重置时间。
- Bungie public milestones 轮换数据基础接入。
- Bungie public vendors 商人数据基础接入。
- 遗失区域从公开里程碑中尽力识别。
- 周报/掉落地图只展示可确认来源，不展示猜测内容。
- QQ/微信群可复制日报文本。

### 活动和 Raid

- 读取 Bungie 最近活动。
- PVE/PVP/其他活动基础摘要。
- Raid/Dungeon 完成次数和尝试次数基础统计。
- 首页活动区域展示近期摘要。

### Loadout 和操作计划

- 本地 loadout 模板。
- loadout 转移计划。
- 单件装备操作计划。
- 操作计划和实际写操作分离。

### 写操作

- 锁定/解锁。
- 装备物品。
- 仓库到角色转移。
- 角色到仓库转移。
- Bungie Scope 提示。
- 本地写操作开关。
- 二次确认。
- 写操作日志。

### AI 和 d2-skill 参考能力

- AI 配置和连接测试。
- 支持 OpenAI 兼容接口、DeepSeek、自定义兼容接口。
- 仓库 AI 分析。
- 单件装备 AI 解读。
- AI 输出分区：事实、分析、建议、操作提醒。
- `d2.*` 工具清单。
- 工具协议不暴露 API Key、client secret、access token、refresh token。
- 工具审计日志。
- 诊断导出包含写操作日志和工具调用摘要，自动脱敏。
- 本地 HTTP 工具发现和注入式调用骨架。

## 不做或长期保持谨慎

- 不内置任何人的 Bungie API Key、Client ID、Client Secret。
- 不默认暴露公网服务。
- 不让 AI 自动执行写操作。
- 不直接复制第三方网站页面或私有数据。
- 不展示无法确认的数据。
