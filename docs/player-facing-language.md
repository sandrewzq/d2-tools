# 领域术语与玩家文案字典

这份文档是项目中领域术语和“内部术语 → 玩家界面用语”的唯一对照表。内部类型、API、日志和诊断可以保留技术术语；标题、说明、按钮、空状态、状态消息、通知和 AI 回复必须使用玩家能够直接理解的表达。

## 使用规则

- 新增玩家可见文案前先查本字典，不在页面内自行发明同义词。
- 新的内部术语需要出现在玩家界面时，必须在同一次改动中补充本字典。
- 技术标识默认不显示；确需提供时只放在设置页、诊断导出或明确的开发者工具中。
- 文案优先说明玩家正在看什么、能做什么、为什么不可用，不解释内部数据结构。
- `Perk` 和 `Roll` 是 Destiny 2 玩家常用术语，可以保留，但必须按下表严格区分。

## 领域术语

| 术语 | 统一含义 | 不使用 |
|---|---|---|
| 账号 | 玩家在 Bungie / Destiny 下的游戏账号资料，包含角色、仓库、材料和活动。 | 用户、登录态 |
| 角色 | 账号下可游玩的猎人、泰坦或术士；持有当前装备、背包装备和游戏内配装栏。 | 职业、人物 |
| 仓库 | 账号级装备存储空间，与角色背包和当前装备不同。 | 库存、背包 |
| 资料库 | 本地保存的 Bungie 游戏定义数据，用于将装备、Perk、商人和活动等编号解释为可读信息。 | Manifest、资料包 |
| 本地方案 | d2-tools 保存的配装模板，描述目标角色和一组期望装备；不是游戏内原生配装栏。 | 模板、LoadoutTemplate |
| 游戏内配装栏 | Destiny / Bungie 提供的角色配装槽位，可应用到角色或用当前装备覆盖。 | 本地方案、模板 |
| 配装对象 | 配装工作台中可选择和操作的一项，可以是本地方案或游戏内配装栏。 | entry、列表项 |
| 转移计划 | 为使目标角色满足本地方案而生成的装备移动和穿戴安排。 | 操作列表、执行步骤 |

## 资料与版本

| 内部术语 | 玩家界面用语 | 使用说明 |
|---|---|---|
| Manifest | 资料库、游戏资料库、这个版本 | 根据语境选择，不直接显示 Manifest |
| Manifest version | 资料库版本 | 普通页面显示日期版本；完整构建号只用于诊断 |
| hash / item hash | 不在主界面显示 | 诊断工具中使用“版本编号” |
| equipment definition | 装备基础信息 | 不使用“装备定义”作为玩家标题 |
| collectible definition | 获取方式 | 不显示上游定义名称 |
| source status | 获取状态 | 使用“当前可获得、来源已记录、暂未确认”等结果文案 |
| definition component | 资料内容 | 不向玩家解释组件或数据表 |

## 商人与账号装备

| 内部术语 | 玩家界面用语 | 使用说明 |
|---|---|---|
| Offer | 商人售卖、这条售卖 | 按钮使用“查看这条售卖” |
| vendor sale item | 商人售卖装备 | 不使用“售卖对象” |
| inventory item / item instance | 仓库装备、账号中的装备 | 按实际位置可写“猎人背包中的装备” |
| instance ID | 不在主界面显示 | 诊断工具中使用“装备记录编号” |
| current object | 当前查看、这件装备 | 不使用“当前对象” |
| location context | 所在位置、来自 | 不使用“入口上下文” |
| API field unavailable | 暂未获取 | 不解释接口字段缺失 |

## Perk 与 Roll

| 术语 | 统一含义 | 玩家界面示例 |
|---|---|---|
| Perk | 一个独立的武器能力或插槽选项 | 当前启用 Perk、只看推荐 Perk |
| Perk 池 | 当前装备版本可能出现的全部 Perk | 完整 Perk 池 |
| Roll | 一件仓库装备或商人售卖实际生成的完整配置 | 本件 Roll、售卖 Roll |
| selected Perk | Roll 中当前生效的 Perk | 当前启用 Perk |
| switchable Perk | Roll 中拥有但未启用的 Perk | Roll 内可切换 |
| recommended Roll | 面向具体玩法的一套目标 Roll | PvE 推荐 Roll、PvP 推荐 Roll |
| mod recommendation | 独立于 Roll 的模组建议 | 模组建议 |

大师杰作属于 Roll；模组、外观和记录器不属于 Roll。

### 异域武器

| 内部术语 | 玩家界面用语 | 使用说明 |
|---|---|---|
| exotic intrinsic | 异域固有能力 | 作为异域武器的核心能力优先展示 |
| fixed perk set | 固定配置、全部固定 Perk | 不使用“随机 Roll”或“完整 Perk 池” |
| catalyst | 异域催化、催化进度 | 明确区分未获得、进行中和已完成 |
| catalyst objective | 完成条件 | 直接显示目标和总数，例如“熔炉竞技场击杀 250” |
| catalyst stat bonus | 催化完成奖励 | 同时显示基础值、增加值和最终值 |

固定配置的异域武器不做随机 Roll 筛选，也不展示推荐 Roll 命中；可以提供 PvE / PvP 使用建议，但不能伪装成可更换的 Perk 组合。

## 推荐与 AI

| 内部术语 | 玩家界面用语 | 使用说明 |
|---|---|---|
| personal knowledge | 我的推荐 | 使用“保存到我的推荐” |
| built-in knowledge | 应用推荐 | 不使用“内置知识库” |
| external knowledge | 在线补充推荐 | 不使用“外部知识查询” |
| knowledge priority | 推荐来源 | 对玩家说明优先使用哪一套推荐即可 |
| evidence | 依据、信息来源 | 使用“可以查看依据” |
| official facts | 装备与售卖信息 | 不使用“官方事实”作为卡片标题 |
| analysis object | 当前查看 | 不使用“分析对象” |

## 原型与系统状态

| 内部术语 | 玩家界面用语 | 使用说明 |
|---|---|---|
| fixture / mock / structure sample | 演示数据 | 明确不代表当前真实库存或账号数据 |
| fact model / data object | 不向玩家展示 | 只用于设计和开发文档 |
| adapter / IPC / schema | 不向玩家展示 | 仅用于开发和诊断 |
| stale cache | 资料可能不是最新 | 同时提供“检查更新”或“立即更新” |
| unknown | 暂未确认 | 能说明原因时补充下一步 |

## 游戏语义颜色

弹药类型和伤害属性使用接近游戏认知的固定语义色。文字标签必须始终保留，不能只依靠颜色区分。

### 弹药类型

| 类型 | 语义色 | 深色界面建议色 |
|---|---|---|
| 主弹药 | 白色 / 浅灰 | `#E9EEF2` |
| 特殊弹药 | 绿色 | `#7FD79B` |
| 重型弹药 | 紫色 | `#C991FF` |

### 伤害属性

| 属性 | 语义色 | 深色界面建议色 |
|---|---|---|
| 动能 | 中性白灰 | `#D7DEE3` |
| 电弧 | 亮蓝 / 青蓝 | `#59D2F4` |
| 烈日 | 橙色 | `#F59A45` |
| 虚空 | 紫罗兰 | `#B888F7` |
| 冰影 | 冷蓝色 | `#7EA8FF` |
| 缚丝 | 亮绿色 | `#66D7A1` |

正式 UI 应把这些颜色沉淀为语义 token，例如 `--game-ammo-heavy` 和 `--game-damage-arc`，不要在组件中重复硬编码颜色。

## 禁用表达

普通玩家界面不得直接出现以下表达：

- “当前 Manifest”“Manifest 构建号”“物品 Hash”。
- “查看技术标识”“Offer 详情”“账号实例”“装备定义”。
- “事实模型”“数据对象”“接口样本”“结构样本”。
- “个人知识”“内置知识库”“外部知识”。
- 无法区分单个 Perk 与整套 Roll 的“当前推荐”“推荐组合”。

## 改写示例

| 不使用 | 改为 |
|---|---|
| 全部候选来自当前 Manifest | 这里列出这个版本可能出现的全部 Perk |
| 查看此 Offer 详情 | 查看这条售卖 |
| 当前账号实例 B | 仓库装备 B |
| Manifest 其他 Perk | 这个版本的其他 Perk |
| 模拟查询外部知识 | 在线补充推荐 |
| 保存为个人知识 | 保存到我的推荐 |
| 当前对象缺少接口字段 | 这件装备的信息暂未获取完整 |
