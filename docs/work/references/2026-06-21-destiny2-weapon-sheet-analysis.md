## 0. 关联小黑盒帖子分析

小黑盒帖子《命运2-凯旋丰碑-全种类武器推荐》与腾讯表格是同一套内容的互补形式：

- **帖子作者**：日栎
- **表格制作者**：Aegis（在帖子正文中明确标注）
- **帖子作用**：从"武器框架"维度给出宏观评价和选择建议
- **表格作用**：从"具体武器 + perk 组合"维度给出微观推荐

### 0.1 帖子主要内容

帖子按武器类型逐一分析各框架在当前终局环境（凯旋丰碑 / 终局 PVE）中的表现，核心观点包括：

**自动步枪**
- 支援框架：小众，但能在某些内容中定义角色定位
- 速射框架：自动步枪中的异常值，伤害曲线扎实
- 平衡 450 射速：表现与速射相近，但带有热量收益
- 精密框架：射程比高冲击更差，伤害曲线也更差
- 适配框架：易用性高，但在低光等环境中不算惊艳
- 高冲击框架 / 攻击框架：表现平庸或易用性差

**脉冲步枪**
- 微型导弹：削弱后依然优秀，能打出可观伤害并生成超能
- 动态（540RPM）/ 平衡（540RPM，热量除外）：可用
- 高冲击：易用性最低，伤害曲线差

**斥候步枪**
- 平衡 260：弹匣大，伤害曲线不错
- 速射：曾经领头羊，现在依旧扎实
- 轻质：有易用性优势
- 高冲击 / 精密 / 攻击：手感或伤害曲线较差

**微型冲锋枪**
- 激进爆弹：表现扎实
- 平衡 900RPM：和平守护者流派毕业选择
- 适配 / 攻击：略差于轻质
- 精密：各方面最差

**榴弹发射器**
- 区域拒止：用途多样，可获取超凡能量、施加溅射、打总伤害
- 微型导弹 / 内爆弹药：适合移动
- 波形 / 双发尖刺 / 轻质尖刺：基本被压过或不相关

**融合步枪**
- 攻击 / 加速线圈：加强后单弹匣爆发 DPS 最佳
- 高冲击 / 加速线圈：总伤害异常偏高，被低估
- 速射 / 加速线圈：易用性最好的融合步枪
- 适配 / 精密：中规中矩或偏弱

**偃月**
- 攻击：整体伤害曲线最佳
- 适配：适合射击目标并保留特殊弹药
- 速射：总伤害偏弱

**霰弹枪**
- 重型点射：大多数输出内容中最现实的选择
- 速射 / 身体：12P 最高射击次数
- 轻质 / 身体：生活质量高，但伤害曲线糟
- 精准重击 / 速射独头弹 / 精密：比重型点射差

**狙击枪**
- 干扰：符合线性融合步枪场景，伤害曲线也好
- 动态 140：总伤害高，perk 上限高
- 速射：DPS 更好，兼容事不过四
- 适配 / 攻击：没有真正优势

**机枪**
- 高冲击：总伤害高于其他框架
- 速射：易用性别扭
- 平衡 900RPM：总伤害明显差于其他

**火箭发射器（带群狼猎手）**
- 铸造者 / 波形：整体最佳
- 高冲击 / 适配：可用但不算优秀
- 精密 / 攻击 / 轻质 / 涡流：平庸或较差

**其他要点**
- 高手炮：动态 180RPM 搭配幸运裤时 DPS 疯狂
- 弓箭：高冲击 / 充能弩弹搭配补弹 perk 有潜力

## 2. 与 d2-tools 项目的对照分析

该表格的内容与 d2-tools 当前重点推进的**社区 Perk 推荐**功能高度重合：

- 表格左侧的 perk 图例说明，对应社区推荐中的 `PerkCombo.note` 和 `WeaponRecommendation.disclaimer`。

- 表格按副本/活动（突袭）分组武器，与设计中"按活动类型过滤推荐组合"的后续扩展方向一致。

## 3. 价值与风险

### 3.1 价值

1. **验证现有 UI**：表格中的武器和 perk 组合可以直接用来验证武器详情弹窗的"社区推荐"区块、仓库命中提示是否正常工作。
2. **补充 DIM wishlist**：DIM wishlist 多为英文且规则密集，该表格提供了中文、按副本分组、带说明的轻量参考，适合普通玩家。
3. **数据源候选**：未来可以扩展 `CommunityPerkSource`，支持导入这类结构化表格（CSV/JSON），作为 `DimWishlistSource` 和 `AiLightggSource` 之外的第三种来源。
4. **与 AI 分析结合**：AI 可以在分析玩家仓库时引用表格中的"人上人""小人上人"等分级说法，输出更符合中文玩家习惯的建议。

### 3.2 风险与约束

1. **数据来源**：表格为社区玩家 LightningStorm 整理，非官方数据，需要在使用时标注"社区推荐仅供参考"。
2. **维护成本**：游戏版本更新后 perk meta 会变化，表格需要持续维护，否则推荐会过期。
3. **版权/授权**：虽然表格已设为公开可查看，但若要在程序中内置或分发，需要获得作者授权。
4. **结构化难度**：表格中 perk 以图标呈现，自动提取为可消费的 `PerkCombo` 需要人工录入或图像识别，成本较高。

## 4. 优先级与下一步建议

### 4.1 优先级建议：中

- 不建议在当前 Phase 3（`AiLightggSource`）之前将其作为内置数据源。
- 建议在社区 Perk 推荐功能 UI 稳定后，作为**测试数据集**和**未来数据源扩展**的参考。

### 4.2 下一步可执行动作

1. **短期（验证用途）**
   - 将表格中少量武器（如突袭部分的 10 件）人工录入为测试用 `WeaponRecommendation`。
   - 在本地构建中验证武器详情弹窗、仓库命中提示、资料库入口的展示效果。
   - 检查这些武器的 perk 名称与项目现有 `perks.ts` / `perkSearch.ts` 的中文映射是否一致。

2. **中期（数据源扩展）**
   - 在 `communityPerkRecommendationService.ts` 中预留一个"本地社区表格"数据源接口。
   - 设计一个轻量的 JSON/CSV 格式，能够表达"武器 hash + PVE/PVP perk 组合 + 说明"。
   - 在设置中增加"导入社区推荐表"入口，默认不内置任何数据。

3. **长期（生态方向）**
   - 与表格作者沟通授权和维护方式。
   - 评估是否将该表格作为可选的社区数据源之一（类似 DIM wishlist 导入）。

## 5. 结论

该腾讯表格是一份**Destiny 2 凯旋丰碑中文武器 perk 推荐表**，结构清晰、按 PVE/PVP 分区、按副本分组，与 d2-tools 正在推进的**社区 Perk 推荐**功能天然契合。当前最合理的用法是：

- 作为 Phase 1/2 功能的验证数据集；
- 作为未来"本地社区推荐表"数据源的设计参考；
- 不作为默认内置数据，避免授权和维护风险。
