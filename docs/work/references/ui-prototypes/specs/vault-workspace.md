# 仓库工作台契约

稳定契约标识：`vault.workspace`。

## 结构

仓库页固定包含筛选列表、清理工作台、同名对比和推荐数据四个工作区。四个工作区消费同一份账号实例集合，不得分别维护简化列表或 archive 页面。

## 数据与操作

- 已读取数量和物品实例来自当前 Profile 快照；当前不展示仓库最大容量或使用率，因为该值没有稳定可读来源。
- 图标、名称、类型、槽位、Perk 和护甲属性来自当前 Manifest 与实例数据。
- 标签、备注、清理候选和个人目标只来自本地持久化数据；没有玩家结论时显示未知或空状态。
- 锁定、装备、转移和批量操作继续调用现有 action / IPC；原型按钮不代表可以跳过确认、权限或错误恢复。
- 同名对比按当前 Hash 和实例标识分组，不能按本地化名称猜测。
- DIM、社区推荐和个人知识分别展示来源，不合并成系统评分。

## 状态

正常、加载、空、失败、部分失败、禁用和进行中都必须保留页面结构。写操作中只锁定相关实例；失败时保留原状态并显示可恢复原因，不得提前更新 UI。

## 视觉与导航

- 四个工作区是完整 `tablist` / `tabpanel`，具备 `aria-controls`、方向键、Home 和 End 模型；不能退回为仅靠 class 切换的伪 Tab。
- 工作区栏是仓库内容层的独立连续章节，不复用共享页面命令栏。左侧四个 Tab 使用 `34px` 分段控件；右侧“已读取 / 当前显示 / 配装命中”使用三枚彼此独立、间距 `5px`、高度 `22px` 的中性 / 蓝色 / 紫色胶囊。
- 筛选工作台位于筛选结果顶部，结果列表获得完整宽度；工作台、结果列、清理账本和对比行使用直角连续表面，只有独立实例对象使用 `6px` 圆角。筛选结果中的配装引用是保护状态，未锁定不构成清理建议。
- 筛选工作台标题区使用章节底色，不使用抬升卡片底色；标题、当前范围、提示和清空操作保持同一行的 `52px` 标题带，窄屏再折为纵向。

## 装备筛选模式

- `武器 / 护甲 / 全部` 是单选筛选范围，使用 `aria-pressed` 的分段控件，不是工作区 Tab。它决定顶部工作台中哪些领域条件可见。
- 共同条件为搜索、槽位、本地标签、锁定状态和排序。武器模式保留武器类型，以及在正式资料字段可用时的弹药和框架；护甲模式显示可组合的生命、近战、手雷、超能、职业、武器六维属性条件。两类条件不能同时露出或互相筛选。
- 每条护甲条件由属性、`≥` 和手动输入的整数阈值组成。条件之间为 AND；重复属性不新增第二条，而是更新已有条件。总属性不再作为筛选门槛，只可作为排序维度；护甲默认排序为已选属性合计降序、总属性降序。
- 武器、护甲和全部各自保留筛选草稿。切换范围时，护甲条件不参与其他范围的筛选，切回护甲自动恢复。结果数先表示真实命中总数，再在必要时说明只渲染前 72 件。
