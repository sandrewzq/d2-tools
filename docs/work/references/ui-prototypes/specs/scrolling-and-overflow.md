# 滚动与溢出契约

本契约适用于三个冻结原型以及后续还原的 Prototype、Web 和 Desktop 共享 UI。

## 总原则

- 产品页面只允许纵向滚动，不得出现水平滚动条。
- 不得用 `overflow-x: hidden` 掩盖超宽布局。它只是 Shell 和已确认滚动容器的最后防御；组件本身必须通过 `min-width: 0`、`minmax(0, 1fr)`、换行、响应式网格或字段重排适配宽度。
- 同一列最多只有一个纵向滚动容器，禁止父子同时使用 `overflow-y: auto`。
- 滚动条是可见的导航反馈，不做完全隐藏或只在悬停时出现的配方。

## 滚动所有权

| 场景 | 滚动容器 | 规则 |
|---|---|---|
| 普通菜单页 | 主内容区 | Shell、顶部栏和主侧栏不滚动 |
| 商人、资料库等长目录 | 主内容区 + 必要的左侧目录 | 目录可独立纵向滚动；中央区块不再创建子滚动 |
| 右侧上下文 | 默认跟随页面或 sticky | 只有内容确实超过视口时才独立纵向滚动 |
| AI 抽屉、实例栏、模态详情 | 弹层内容区 | 使用 `overscroll-behavior: contain`，打开时不带动背景 |
| 小屏单列布局 | `body` 或页面主区 | 原有左右分栏改为纵向堆叠，不转为水平轨道 |

原型中的明确滚动容器使用 `data-scroll-region="page|pane|overlay"` 标记。该标记表达布局所有权，不包含业务逻辑。

## 统一外观

- 滚动条总宽度为 `10px`，滑块使用 `2px` 同轨道色边框，形成约 `6px` 的可见宽度。
- 滑块使用胶囊圆角；默认、悬停和按下状态分别使用 `--scrollbar-thumb`、`--scrollbar-thumb-hover` 和 `--scrollbar-thumb-active`。
- 轨道使用所在面板的语义背景 `--scrollbar-track`，不绘制与面板无关的高对比长槽。
- light / dark 共用同一组语义 token，页面 CSS 不得单独写滚动条颜色、宽度或圆角。
- 固定高度的目录、正文和抽屉使用 `scrollbar-gutter: stable`，避免滚动条出现时内容横向跳动。

## 禁止水平滚动

- 商品、Offer、材料和声望奖励必须使用响应式网格换行。
- 首页仄八件轮换在宽屏为 `4 × 2`，随宽度降为 2 列和 1 列，不得建立水平卡片轨道。
- 章节导航、模式切换和标签组优先换行；正式应用中按钮过多时收入“更多”菜单，不允许左右拖动。
- 宽表格必须允许单元格换行、调整列宽，或在窄屏转成键值卡片；不得使用固定 `min-width` 配合 `overflow-x: auto`。
- 浏览器不应出现可水平移动的产品内容，鼠标滚轮、`Shift + 滚轮` 和触摸板水平手势均不应改变主界面水平位置。

## CSS 所有权

- `prototype-design-system.css` 唯一负责滚动条 token、WebKit / Firefox 外观和公共滚动行为。
- 页面 CSS 只允许声明 `overflow-y`、容器高度、响应式堆叠和哪个元素拥有滚动；已确认的滚动容器可使用 `overflow-x: hidden` 作为最后防御，但不得用它掩盖布局超宽。
- 页面 CSS 不得声明 `::-webkit-scrollbar`、`scrollbar-color`、`scrollbar-width` 或水平滚动轨道。

## 验收

1. 三个原型在 light / dark 下的滚动条宽度、轨道、滑块、悬停和按下状态一致。
2. 全应用原型的主内容、长目录和 AI 抽屉只在指定纵向轴上滚动。
3. 商人八件轮换、其他 Offer、声望奖励、详情导航、目标来源和表格均不出现水平滚动条。
4. 1280、980 和 760 宽度下内容不被裁剪，不依赖隐藏溢出伪造通过。
5. 独立面板滚到顶部或底部时不意外带动父容器。
