# 仓库页实现对照

本文件定义仓库静态原型迁入共享 UI 前的字段、操作和状态边界。原型只消费当前 `account-workspace-snapshot`；正式实现必须改用仓库 ViewModel 和现有 action，不得把冻结快照数量写入产品组件。

## 区域与字段

| 原型区域 | 数据来源 | 必须呈现 | 约束 |
|---|---|---|---|
| 顶部统计 | `account.vaultItemCount`、`vaultIndexes`、`loadoutMatchedIndexes` | 已读取、当前显示、配装命中 | 不能显示没有稳定来源的仓库容量或使用率 |
| 筛选列表 | `vaultIndexes[]`、对应实例与 Manifest | 图标、名称、类型、光等、位置、实例状态 | 配装引用优先标记为保护；未锁定不等于可清理 |
| 清理工作台 | 本地 `vault-tags`、当前实例集合 | 玩家明确的可清理标记、选择项、批量操作状态 | 无本地结论时必须为空态，批量操作禁用且不伪造候选 |
| 同名对比 | `duplicateGroups[].hash`、`indexes[]` | Hash 分组、实例、位置、锁定、配装引用 | 不能按本地化名称分组或自动选出保留项 |
| 推荐数据 | DIM Wishlist、已授权社区来源、个人目标规则 | 每个来源各自状态和可读规则 | 没有快照/授权数据时禁用入口，不虚构命中与建议 |

筛选列表还必须保持领域分支：武器使用类型、弹药、框架和 Perk 查询；护甲使用六维属性组合阈值。每条阈值为属性、`≥`、整数值，多个条件同时成立且同一属性只保留一条。总属性只作为排序字段，护甲默认按已选属性合计、总属性依次降序。武器、护甲和全部范围分别保存筛选草稿，切换范围不丢失护甲条件；正式实现必须直接消费实例属性字段，不得把原型的交互投影带入产品数据层。

## 导航与详情

- 筛选列表、清理工作台、同名对比和推荐数据是同一个 `tablist` 下的四个 `tabpanel`，必须支持左右、Home、End 键。
- 只有 `item.type` 明确为武器或护甲的仓库实例才跳转统一详情；材料、消耗品和其他对象保留仓库信息，不得默认打开武器详情。

## 表面与状态

- 仓库是 `fluid-workspace`：筛选栏与结果栏使用直角 `WorkspaceSplit` / `SurfaceList`，连续实例行只画 `RowLine`。
- 独立仓库对象使用 `ObjectCard` 的 `6px` 圆角；摘要矩阵与空态使用 `SurfaceFrame` 的 `4px` 轻圆角；缩略图和控件使用 `4px`。连续列表和工作区结构仍保持直角。
- 加载、空、失败、部分可用、禁用和进行中都保留四个工作区与 Tab。写操作失败前不得修改实例锁定、位置或标签的显示值。
