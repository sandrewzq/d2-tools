# 配装工作台契约

稳定契约标识：`loadouts.workspace`。

## 对象边界

- 本地模板与 Bungie 游戏内配装栏是两种不同对象，必须显示来源。
- 本地模板支持重命名、删除、生成转移计划和复制缺失清单。
- 游戏内配装栏支持应用和用当前装备覆盖；不能在产品 UI 中伪造本地重命名或删除能力。
- 只有包含有效实例的游戏内栏位进入目录，空栏位不生成示例配装。

## 装备定位

每个条目显示名称、槽位、账号位置、是否已定位和缺失原因。定位使用实例 ID；找不到实例时不得用同名物品替代。应用或转移必须沿用现有 Bungie 写操作、进度、失败恢复和刷新规则。

## 状态

没有模板或有效游戏内栏位时显示明确空状态。部分缺失时继续展示已定位条目；操作禁用原因紧邻按钮，进行中保留原位置直到 API 成功。
