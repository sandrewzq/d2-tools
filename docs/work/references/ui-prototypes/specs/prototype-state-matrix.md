# 原型状态矩阵

三个冻结原型都必须能表达以下状态。状态只定义视觉与信息结构，不定义产品 mock 行为。

页面级状态统一写在 `data-prototype-root` 的 `data-state`；原型工具使用 `data-prototype-state` 切换它。业务状态仍通过组件或槽位的 `data-status` 表达，不能再新增 `data-detail-state` 等并列页面状态协议。

| 状态 | 展示规则 | 禁止事项 |
|---|---|---|
| 正常 | 展示当前确认数据和可用操作 | 固定示例数量冒充真实结果 |
| 加载 | 保留稳定尺寸与主要导航 | 回退显示过期数据 |
| 空 | 保留查询、切换、刷新或创建入口 | 用假对象填满页面 |
| 失败 | 显示失败范围、原因和恢复入口 | 全页静默空白 |
| 部分可用 | 已确认内容继续显示，缺失区单独标记 | 把部分结果标成完整 |
| 禁用 | 只读内容可见，原因紧邻控件 | 隐藏现有功能 |
| 进行中 | 保留旧状态并显示目标、进度与取消边界 | API 返回前提前显示成功 |

全应用原型的页面级状态开关用于工作区验收，首页商人另有模块级状态；武器和护甲详情的状态开关覆盖整个档案。正式应用必须绑定现有 loading / empty / error / partial / disabled / pending ViewModel，而不是复制原型开关。
