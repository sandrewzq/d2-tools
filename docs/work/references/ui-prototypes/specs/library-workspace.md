# 资料库工作台契约

稳定契约标识：`library.workspace`。

## 页面骨架与交互

资料库是 `hybrid-workspace`：上方是直角 `summary-frame` Manifest 摘要，主体是“查询侧栏 + 连续结果列表”的 `WorkspaceSplit`。摘要必须显示激活版本、最新版本、激活时间、检查时间、语言、定义数量和缺失组件；它是资料库状态的唯一摘要外框，内部单元只使用分隔线。

装备与“Perk 与框架”是互斥内容模式，使用完整 `tablist` / `tab` / `tabpanel`，每个 Tab 具有 `aria-controls`，支持左右、Home、End 键。筛选字段、搜索框和清空命令是普通 Control，不得伪装为导航或 Tab。

Perk 模式必须支持“按 Perk 反查武器”：用户选择一条 Perk 后，在同一结果工作区显示关联武器列表和返回入口。关联来自当前账号特性聚合或 Manifest 关联，不能通过武器名称模糊猜测。已读到当前实例的武器可打开统一详情；只读到关联定义时必须明确说明“实例未读取”，不能伪造光等、位置或可用 Roll。

结果区是 `SurfaceList`：每一项为直角 `RowLine`，不使用对象卡边框或圆角。名称、定义属性、账号持有结论、查询时间和来源必须分别使用 `Tone + Priority`。只有跳往详情的按钮是 primary Control；“在账号中查看”只在已匹配当前账号实例时出现。

## 数据来源

- 装备与 Perk 定义、版本、语言和完整性来自当前激活 Manifest。
- 最近查询与收藏来自本地历史，不得用固定名称、别名或数量填充。
- 账号持有状态由当前 Profile 实例匹配，定义对象和账号实例必须区分。
- 获取来源只展示可追踪的官方、商人、轮换或已授权外部来源。
- 账号插槽聚合结果统一称为“已装配特性与框架”；数据中包含 `frames` 时不得统称为“账号已装配 Perk”。

## 更新机制

资料库区域必须显示当前版本、最新版本、检查时间、激活时间和缺失组件。自动检查、自动更新、立即更新与修复继续使用现有 Manifest 服务，失败时保留上一份可用资料库并明确标记时效。

## 状态

搜索无结果、历史为空、资料库未初始化、版本检查失败、部分组件缺失和更新中分别展示；不能用统一空白页隐藏查询与修复入口。

| 状态 | 摘要矩阵 | 查询与结果区 |
|---|---|---|
| 正常 | 版本与完整性为当前快照，状态使用 `success` | 保留当前模式、筛选与连续结果行 |
| 搜索无结果 | 保留最近一次可读 Manifest 摘要 | 显示该查询的独立直角空态，不用相似名称或旧结果替代 |
| 历史为空 | 摘要继续显示 Manifest 可用性 | 侧栏明确本地历史为空，搜索与修复入口仍可用 |
| 未初始化 / 失败 | `pending` 或 `error`，显示缺失组件或失败原因 | 保留查询骨架和修复入口，不渲染模拟定义结果 |
| 部分组件缺失 | `warning`，明确缺失数量 | 仅显示可确认字段；缺失的来源、Perk 或实例结论不能伪造 |
| 更新中 | `pending`，保留激活版本并显示检查/激活时间 | 当前可用定义仍可读，禁止提前声称新版本已激活 |

## 还原映射

| 原型区域 | 真实字段或 action | 数据来源 |
|---|---|---|
| Manifest 摘要 | `version`、`latestVersion`、`activatedAt`、`checkedAt`、`language`、`itemCount`、`perkCount`、`relationCount`、`missingRequiredComponents` | 当前激活 Manifest 服务状态 |
| 查询模式 | 定义搜索 / 已装配特性与框架模式 | 当前资料库查询 ViewModel |
| 查询与筛选 | 查询词、分类、账号持有状态 | Manifest 查询参数；账号持有状态额外来自 Profile 匹配 |
| 最近查询 | 历史条目名称、类型、查看时间 | 本地 `library-history`，不生成别名或虚假收藏量 |
| 装备结果 | 定义名称、图标、类型、属性摘要、详情打开、账号定位 | Manifest 定义 + Profile 实例匹配 |
| 特性与框架 | 名称、描述、类别、关联装备 | 当前账号实例的已装配特性与框架聚合 |
| Perk 反查武器 | 已选 Perk、关联武器定义、当前实例与详情打开 | Perk 到武器关联 + 当前 Profile 实例匹配 |
