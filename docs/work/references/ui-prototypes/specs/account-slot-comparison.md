# 账号装备位置对照契约

## 目标

账号页必须按装备类型和位置组织当前角色的武器、护甲与背包候选，不能把所有已装备物品和所有背包物品拍平成两个长列表。职业分支、机灵、飞船、载具、徽标、任务、材料、外观和其他非战斗物品不得混入该对照区域。

稳定契约标识：`account.slot-comparison`。

## 页面骨架与交互

账号页是 `hybrid-workspace`，由账号数据 Tab、账号身份区、角色上下文切换器和当前 Tab 面板组成。账号目录是完整 `tablist`：每个 Tab 必须有 `aria-controls`，对应面板使用 `tabpanel` 和 `aria-labelledby`，支持左右、上下、Home、End 键切换并移动焦点。

角色不是导航。角色切换器使用 `ContextSwitcher`，以 `aria-pressed` 表达当前角色；切换后只重绘当前角色的对照数据，不改变账号目录的当前 Tab。

装备对照是连续的满宽数据工作区：类别、位置标题和两列边界只使用直角 `PageSection`、`RowLine` 与 `SplitLine`。每件武器或护甲是独立 `ObjectCard`，拥有 `6px` 圆角和唯一对象边框，并可打开对应统一装备详情。“显示全部”是 `secondary` Control，位置为空使用 `4px` 轻圆角 `state-frame`。不得把类别、位置或装备列再包成对象卡。

非战斗数据使用独立 Tab：角色配置、任务与进度、物品与货币、邮政官、活动记录。角色配置和角色背包内的非武器护甲数据全部使用只读行或只读对象卡，不显示手型、对象 hover、箭头、详情文案，也不调用详情 action。邮政官中仍只有武器和护甲可以打开详情。

## 分类与顺序

装备对照只保留两个分类：

1. 武器
2. 护甲

已知位置按以下顺序排列：

1. 动能武器
2. 能量武器
3. 威能武器
4. 头盔
5. 臂铠
6. 胸甲
7. 腿甲
8. 职业物品

职业分支、机灵、飞船、载具、徽标、公会战旗、终结技和动作进入“角色配置”。任务、任务步骤、命令、赏金、神器和赛季记录进入“任务与进度”。记忆水晶、消耗品、钥匙、外观、未装备配置和无法稳定识别的数据进入“物品与货币”；账号级材料与货币继续使用账号材料集合，不伪装为角色装备。

## 位置对照行

每个位置必须包含：

- 位置名称。
- 当前装备数量。
- 当前角色背包候选数量。
- 当前装备列。
- 背包候选列。
- 每件物品的图标、名称、光等、类型和可用的 Roll / 属性摘要。
- 方案命中、写操作处理中等已有状态。
- 武器和护甲提供打开统一装备详情的入口。

背包候选允许默认只展示固定数量，但必须显示总数、剩余数量和“显示全部”操作，不能静默丢弃。

## 数据来源

- 当前装备和背包：当前 Profile 快照。
- 分类与位置：Manifest bucket 定义和账号工作区的稳定映射。
- Roll、属性、方案命中和写操作状态：当前实例 ViewModel。

不得通过装备名称猜测位置；不得把仓库物品混入当前角色背包候选。

## 状态

| 状态 | 行为 |
|---|---|
| 正常 | 按分类和位置显示全部对照行 |
| 位置为空 | 保留位置标题，在对应列显示“暂无” |
| 背包候选较多 | 显示预览数量和“显示全部” |
| 写操作中 | 只标记目标物品，不锁住其他位置 |
| 账号刷新中 | 保留位置结构，分别显示骨架 |
| 读取失败 | 不把旧角色装备冒充为当前快照 |

刷新和读取失败状态必须保留当前 Tab、角色上下文与位置骨架；每个位置的两列分别呈现骨架、空态或失败原因，不能用整页遮罩替代可辨认的对照结构。

## 还原映射

- 原型：`[data-contract-id="account.slot-comparison"]`
- 共享 UI：`AccountSlotComparison`
- 工作区：`slotComparisonRows`
- 行字段：`label`、`category`、`equippedItems`、`inventoryItems`

| 原型区域 | 真实字段或 action | 状态来源 |
|---|---|---|
| 账号身份区 | `Profile` membership、账号名、快照时间、角色数、仓库数量 | 当前账号快照 |
| 角色上下文 | `characters[]`、角色职业、光等、当前角色 ID | 当前 Profile 角色集合 |
| 装备位置行 | `slotComparisonRows` 的位置、已装备项、背包候选、总数 | Manifest bucket 映射 + 实例 ViewModel |
| 装备对象 | 名称、图标、类型、光等、Roll 摘要、配装命中；仅武器和护甲允许详情打开 | 当前实例 ViewModel |
| 位置展开 | 当前角色和位置的展开 action | 仅影响该位置的背包候选预览 |
| 角色配置 Tab | 已装备的职业分支、机灵、飞船、载具、徽标、公会战旗、终结技、动作 | 当前角色 Profile，全部只读 |
| 任务与进度 Tab | 任务与步骤、命令与赏金、神器与赛季 | 当前角色已装备与背包集合，按资料库名称和类型分类 |
| 物品与货币 Tab | 角色携带物品、外观与可选配置、未分类数据、账号材料与货币 | 当前角色背包 + 账号材料集合，全部只读 |
| 邮政官 Tab | 所选角色的邮政官物品 | 只有武器和护甲绑定统一详情，其余只读 |
| 活动记录 Tab | Activity History | 独立读取状态，不借用装备快照伪造结果 |

正式还原时必须复用当前完整位置对照组件。禁止通过 `flatMap` 生成独立的“当前装备”和“角色背包”长列表，也不得创建只在某个视觉变体中使用的简化 DOM。
