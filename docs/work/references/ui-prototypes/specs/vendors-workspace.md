# 商人工作台契约

稳定契约标识：`vendors.workspace`。

## 目录与详情

- 目录按真实地点和商人分组，身份使用 `vendorHash` 或稳定 ID。目录是紧凑文字行，不显示商人头像或首字母替代图标。
- 详情按库存、子库存、任务和声望奖励展示，不能把分类摘要当完整库存。
- 每个 Offer 显示真实图标、名称、类型、成本、数量和当前可确认配置。
- 角色相关库存必须显示当前角色上下文；跨角色结果不得合并成不存在的统一 Offer。
- 首页仄与商人页仄消费同一份当前轮换，首页完整显示本周八件轮换商品，包含“仄浪板”载具，不限定为武器或护甲。
- 库存章节纵向排列；每个章节内的 Offer 使用横向响应式网格，在宽屏为五列，压缩宽度后逐级降为三列和单列。章节分组使用连续标题与分隔线，Offer 才是带 `6px` 圆角的独立对象卡。不得建立水平商品轨道或水平滚动条。

## 时效与异常

显示读取时间和重置边界。加载时不回退旧 Offer；部分详情失败时保留基础销售数据并标明属性或插槽缺失；商人未开放时清除过期轮换。
