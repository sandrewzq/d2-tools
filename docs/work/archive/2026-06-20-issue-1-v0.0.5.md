# Issue #1 / v0.0.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first complete `0.0.5` workflow for weapon-frame filtering, unified bulk movement, and local loadout review in `d2-tools`.

**Architecture:** Extend shared item models first so frame metadata exists everywhere that matters, then wire that metadata into existing library and vault filters, then upgrade local loadout templates and related UI without mixing them with Bungie in-game loadout writes. Reuse the current Electron IPC and core-analysis structure instead of inventing a second feature path.

**Tech Stack:** TypeScript, Electron, React, Vitest, pnpm workspace, Bungie manifest definition cache.
