# 工作文档索引

这个目录保存不适合作为正式入口、但仍有参考价值的工作材料。

维护规则：

- 当前短期待办只写在 [`../todo.md`](../todo.md)。
- 具体手测问题只写在 [`../bug-list.md`](../bug-list.md)。
- 未完成设计或计划放在 `backlog/`，不要删除。
- 已实现、已合并或仅作历史追溯的过程材料放在 `archive/`。
- 外部资料分析、数据源调研放在 `references/`。
- 如果某份工作文档里的内容重新变成当前任务，先把结论合并到 `todo.md` 或 `bug-list.md`，不要让多份文档同时承载当前状态。
