# 桌面仓库页 Tab v2 布局设计记录

> 状态：已由用户确认，后续仓库页 UI 开发按本文作为方向。
> 记录时间：2026-06-29
> 原型文件：`.local-data/tmp/ui-redesign-prototypes/vault-tabs-v2.html`

## 设计边界

- 全局外壳沿用已确认的 [首页与全局外壳 v4](desktop-home-global-shell-v4.md)。
- 仓库页不把筛选列表、清理工作台、同名对比、目标规则和推荐数据全部挤进一个视图。
- 仓库页采用同页 tab 模式，默认进入“筛选列表”。
- 清理和同名对比是明确工作模式，不在默认列表里长期展开。

## Tab 结构

仓库页主 tab：

1. 筛选列表：默认视图，日常查找装备。
2. 清理工作台：批量选择、清理清单、转移目标角色、写操作状态。
3. 同名对比：重复组、roll 对比、保留 / 关注 / 可清理决策。
4. 目标规则：本地武器和护甲目标规则维护。
5. 推荐数据：DIM wishlist 和本地社区推荐导入。

## 筛选列表

筛选列表保留现有通用筛选：

- 搜索：名称、perk、备注、来源。
- 排序。
- 标记。
- 锁定。
- 位置。
- 槽位。
- 清空筛选。

筛选列表再按装备类型切换筛选模式：

- 武器筛选。
- 护甲筛选。
- 全部装备。

## 武器筛选

武器筛选重点是 perk 和武器结构：

- Perk 查询。
- 弹药类型。
- 武器类型。
- 元素。
- 框架。
- DIM 愿望单命中。
- 本地目标命中。
- 小日向命中。
- 配装命中。
- 未标记、未锁、可清理等状态。

## 护甲筛选

护甲筛选保留并强化当前六维筛选：

- 机动。
- 韧性。
- 恢复。
- 纪律。
- 智慧。
- 力量。

六维筛选是护甲模式核心区域，不应被弱化成很小的高级筛选。规则支持添加、清空和组合。

护甲筛选还应保留：

- 职业。
- 护甲槽位。
- 异域 / 传说。
- 能量或其他现有可确认字段。
- 总值和低价值候选。

## 清理工作台

清理工作台只在对应 tab 展示：

- 可清理数量、当前选择数量、未锁数量、目标角色和写操作状态。
- 批量选择规则：可清理、复查、未标记、追加当前结果、清空选择。
- 批量执行：复制清理清单、批量解锁、转移到角色背包。
- 明确说明不会分解装备，最终仍需进游戏手动分解。

## 同名对比

同名对比只在对应 tab 展示：

- 左侧重复组列表。
- 右侧同名装备 roll 对比。
- 快捷操作：打开最高分、选择其余候选、保留这件其余关注、保留这件其余可清理。

## 实现注意

- 现有 `VaultPanel` 已包含筛选、整理、清理、同名对比和批量操作能力；实现时优先重排 UI，不重写业务逻辑。
- `VaultFilterToolbar` 需要保留现有筛选能力，并在视觉上拆出武器 / 护甲模式。
- `VaultOrganizePanel` 的批量操作应迁入“清理工作台”tab，避免默认列表过载。
- `VaultDuplicateGroups` 应迁入“同名对比”tab。
- `VaultTargetRulesPanel` 和推荐数据导入应分别成为“目标规则”和“推荐数据”tab。
