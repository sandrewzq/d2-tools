# T87：仓库武器卡重设计：光等搬进身份行右缘、卡片宽度固定

> 状态：✅ 已通过实窗验收（2026-09-19）
> 合同：`docs/work/references/ui-specs/application-workspaces.md`
> 来源：原记于 `docs/todo.md` 的 T87 行，2026-09-19 迁入本文件，细节以本文件为准。
> 关联：T86（同一张卡的前一轮，本件消除它记下的那条已知代价）。

## 一、问题

承接 T86 的同一张卡，实窗还有两处没人用：

- 身份行右侧整块空着（标准档卡宽 278.8 时未用 132.5px），而事实行四项等分
  把「反势不可挡」截成「反势不可…」；
- 卡片会被 `1fr` 拉伸填满行宽，同排卡不等宽。

## 二、改法（已改完）

1. 光等从事实行最右搬到身份行第三列（`auto` 列，贴卡片右缘），
   事实行只剩弹药 / 属性 / 勇士三项，每项够宽，勇士词条完整；
2. 网格改成固定卡宽 `repeat(auto-fill, 260px)` + `justify-content: start`
   （紧凑 `224px`、舒适 `296px`），一行排几张只由结果列宽度决定 ——
   窗口宽减左侧菜单栏（默认 `184px`，≤1280 为 `160px`，≤980 为 `72px`，≤760 为 `64px`）
   再减滚动条 10px 与网格内边距 24px；
3. 逐处收 6px 还给来源面板：内边距上下各收 `1px`、主区行距 `4 → 3`、
   事实行下限 `22 → 20`，紧凑档另外把卡高 `172 → 178`
   （卡宽只有 224，名字必折两行，身份行要从 40 长到 51）。
