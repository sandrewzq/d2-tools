# T66：链接导入的预览与起名放回弹框里

> 状态：🟢 代码已改并自验通过，待用户复验（2026-09-17）
> 用户诉求（两张截图 + 原文「csv的导入起名是在弹框里 / 链接同步的起名也应该在弹框里」）：
> 表格导入弹框里，选完文件就能在框内起名并确认；链接这条路读完却把弹框收掉，起名落到页面里。
>
> ⚠️ 后续：本文「不改本地文件那条路」是被 T68 推翻的——用户接着问「文件为什么不能用弹框呢」
> 并选了「先开框、框里再选文件」，本地文件那条路如今同样在弹框内确认。本文其余部分描述的是 T66 当时的状态。

## 今天三条路各自的样子

| 入口 | 链接输在哪 | 预览与起名在哪 |
|---|---|---|
| 导入人工推荐表格 | 无 | **弹框内**（选文件 → 预览 → 起名 → 新建 / 覆盖，全在一个框里） |
| 从链接同步（首次导入） | 弹框内 | **页面内**（读完链接弹框自动关掉，卡片落在导入区下面） |
| 来源行上的「同步」 | 不用输，来源自己记着链接 | **弹框内**（内容变了才弹预览，起名与确认都在框里） |

三条路里只有第二条把同一件事拆到了两个面上：链接在一个已经关掉的框里输，
预览与起名落在页面上。这一条改成与另外两条一样。

## 改法

- 读完链接**不关弹框**：预览卡（文件与来源说明、导入件数、来源名输入框、新建 / 覆盖两个动作、
  展开写法冗余与问题行说明）就在框内、链接输入框的下面渲染。
- **一次导入只有一份待确认的预览**。打开链接弹框＝开始一次新的链接导入：
  页面上那份还没确认的本地文件预览会被放下（它同样没有写进任何数据，重新选一次文件即可）。
  这样「框开着时，框里那张卡必定是链接读来的」是个不变量，不用额外记「这份预览是哪条路的」。
- **关掉弹框＝放弃这次导入**（读到的内容不写库）。关闭按钮、`Escape`、点遮罩三条关法共用同一段收尾。
- **内容没变**（「已是最新」）时没有可确认的东西：照旧只说一句，并把弹框收掉。
- **读取失败的提示改在框内显示**。原先它落在页面底部那张反馈行上，而遮罩底色是 62% 黑、
  框又占住屏幕中央——那句话其实在遮罩后面，用户看不到。既然整条链接流程现在都在框里，
  提示也跟着在框里。（表格导入弹框有同样的问题，这次不动它，见「如实记录」。）
- 确认成功（新建或覆盖）后收起弹框。

  用户这次点名的是链接同步；本地文件那一步没有可以先输点什么的弹框，凭空加一个框是另一件事。~~
  **（已被 T68 推翻：本地文件那条路也改成「先开框、框里再选文件」。）**

- **不改导入入口的两个按钮**：T63 定案的两条路（本地文件 / 用户给的链接）原样保留。
- **不动表格导入弹框**。

### 如实记录

- **断行那条样式规则是这次改动的必然后果，不是顺手加的美化**：卡片从整页宽（页面上）搬进 720px 的弹框后，
  长链接每次都会压到右边的计数上；实测的 620 / 395 / 225 三个数就是改前改后的差别。所以它算本条任务的一部分。
- **第一次变异没打中**：`overflow-wrap: anywhere` 这一行在样式表里另有六处完全相同的写法，
  按裸文本替换删掉的是**别的规则**那一行，于是「漏网」了一次；把变异锚到「选择器 + 这一行」之后才真的变红。
  记在这里是因为它说明**按裸文本做样式变异不可靠**——同一行文本在同一文件里可能重复。
- **失败提示这条顺带只改了链接弹框**：同样的写法（提示落在页面底部、被遮罩挡住）在「导入人工推荐表格」弹框里
  一模一样，这次没动它——用户点名的是链接这条路，动另一个弹框会多出一份没要求的改动面。
  要一起改的话，把 `feedbackLine` 在表格弹框里也渲染一份即可（一行）。
- **弹框内交互没有专门的焦点用例**：Tab 循环与 `Escape` 走的是既有的 `useModalFocusTrap`，
  这次只把 `Escape` 的收尾换成 `closeLinkDialog()`；关闭语义由「关掉框＝放弃这次导入」那条用例钉住。
- 存储、主进程、IPC、下载与解析链路一律未动：这次只改界面把预览卡摆在哪个面上。

## 验收判据

1. 在「从链接同步」弹框里贴链接并读取后，**弹框不关**，预览与来源名输入框、新建 / 覆盖两个动作都在框内。
2. 确认成功后弹框才收起；起名与确认的口径与表格导入、来源行同步完全一致。
3. 关掉弹框（关闭按钮 / `Escape` / 点遮罩任一）后，页面上不会冒出那张预览卡，也没有任何数据被写入。
4. 内容没变时只说「已是最新」，并收起弹框。
5. 读取失败时弹框不关，失败原因显示在弹框内。
6. 本地文件那条路（页内预览与起名）与今天一模一样。
7. 五道闸门与 `pnpm check` 全绿。

重新打包后进 仓库 → 推荐来源 → 「DIM 文本」那一行点「从链接同步」：贴一个链接、点「读取链接」后，
