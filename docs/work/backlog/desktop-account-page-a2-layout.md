# 桌面账号页 A2 布局设计记录

## 设计边界

- 全局外壳沿用已确认的 [首页与全局外壳 v4](desktop-home-global-shell-v4.md)。
- 账号页不推倒重来，保留当前“账号目录 + 账号摘要 + 角色装备 + 活动复盘 + 材料 + 邮政官”的内容结构。
- 账号页重点优化角色装备与背包展示，不把背包隐藏到需要多次点击后才能看到的位置。
- 右侧辅助区不应过宽，只保留低频摘要，不抢主工作区宽度。

## 布局方向

账号页采用 A2 布局：

- 左侧账号目录：账号概览、角色装备、活动复盘、材料消耗、邮政官。
- 顶部账号概览：账号名、仓库占用、材料数量、邮政官风险、最近读取时间。
- 角色切换：猎人、泰坦、术士三角色 tab，保留职业图标 / emblem 和光等。
- 主工作区：当前角色装备与背包。
- 右侧窄摘要：活动、材料、邮政官风险等低频辅助信息。
- 下方锚点区：完整活动复盘、材料清单、邮政官列表。

## 背包展示

角色装备区按槽位展示“装备中 + 背包候选”：

- 每个槽位一个分组，例如动能武器、能量武器、威能武器、护甲槽位。
- 分组左侧展示当前装备中的物品。
- 分组右侧展示背包候选预览，首屏至少显示多件候选，避免用户感觉“背包不显示了”。
- 候选可显示 DIM wishlist、配装命中、小日向命中、清理候选等标记。
- 背包数量较多时提供“展开全部背包”或槽位内加载更多，不能一次性渲染导致卡顿。

## 右侧辅助区

右侧宽度控制在窄摘要范围，建议约 260px：

- 邮政官风险：例如猎人 18/21。
- 活动摘要：PVE / PVP 完成情况。
- 材料摘要：关键材料状态。

右侧不承载大段列表、不放主要操作入口；主要操作仍在角色装备和背包主工作区。

- 背包预览仍需保留现有 lazy-load / 限量渲染策略，避免重新引入账号页卡顿。
