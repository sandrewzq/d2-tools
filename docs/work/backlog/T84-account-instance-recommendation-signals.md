# T84：账号实例推荐对照：卡级信号跟卡片自己的事实走，环恢复常蓝

## 一、问题

实窗看到「当前启用」在同一栏里有一蓝一红两种样子。

根因是「本件当前装着、来源没要它」这枚叉额外挂了一道「这一栏符合 / 不符」的门控
（`mismatch` 取 `state === "different"`）：同一个事实在「符合」栏里静默、在「不符」栏里又变红又打叉。

而「符合」说的是你**拥有**来源要的那项（哪怕没装），不等于你装的就是它——
拿栏位结论去决定卡片长什么样，就把一条事实画成了两种。

## 二、改法（已改完）

1. 判据只读卡片自己的事实（`!hit && active`，去掉 `state` 门控），叉在「符合」栏里也照画。
2. 环不再跟着染红，颜色只表示「当前启用」，红字只作加强，形状（叉）才是那条不许丢的通道。
3. 两列表头图例同步写成「环＝当前启用，叉＝来源没要」。
4. 合同与架构守卫跟上。

## 三、已知代价

一栏的表头写「符合」、栏内某张卡却带红叉——两个信号各说各的事实，
实窗复验时重点看这处会不会被误读成整栏判定。

## 四、复验要点

- 同一栏里「当前启用」的环色不再因栏位结论而变；
- 「本件当前装着、来源没要它」在「符合」栏里也画叉；
- 表头图例与栏内信号对得上。
