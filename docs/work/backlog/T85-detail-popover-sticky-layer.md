# T85：详情浮层被来源卡吸附栏头切成两截：三层分家

> 状态：✅ 已通过实窗验收（2026-09-19）
> 不变量：`docs/development.md`
> 来源：原记于 `docs/todo.md` 的 T85 行，2026-09-19 迁入本文件，细节以本文件为准。

## 一、问题

实窗截图：说明浮层被切成上下两截，中间横穿一条「叉＝来源没要」。

根因是条目与吸附栏头同层——条目悬停 / 聚焦 / 打开时是 `--layer-sticky - 1`（9），
来源卡顶部的吸附栏头是 `--layer-sticky`（10）且不透明；浮层在条目的层叠上下文里，
所以整块跟着条目停在栏头之下，而浮层是从卡片**往上**开的，
第一行卡片的浮层必然跨过那条带子，中段就被吃掉。

`--layer-sticky` 定义在 `packages/ui/src/styles/foundation/00-tokens.css:110`，值为 10。

## 二、改法（已改完）

栏头降到 `--layer-sticky - 2`（8），顺序变成
页签(+1) > 悬停卡片与浮层(-1) > 栏头(-2) > 静态内容(0)；
栏头仍然压得住从它下面滚过去的卡片（那些停在 0）。

## 三、已知代价

鼠标停在滚到栏头下面的卡片上时，那张卡片连同浮层会一起画在栏头之上——
选择是让浮层可读，而不是让卡片留在栏头下面。

## 四、未处理

底部吸附的写面板仍是 `--layer-sticky`，推荐区的卡片离它很远，这轮不动。

## 五、复验要点

- 第一行卡片的说明浮层不再被栏头横切；
- 滚动时栏头仍能压住从它下面滚过去的静态卡片；
- 鼠标停在栏头正下方的卡片上时，卡片与浮层画在栏头之上（已知代价，确认可接受）。
