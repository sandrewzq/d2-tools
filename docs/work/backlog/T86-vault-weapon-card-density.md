# T86：仓库武器卡瘦身：来源只列 2 条、状态与快捷操作并成一行

> 状态：✅ 已通过实窗验收（2026-09-19）
> 合同：`docs/work/references/ui-specs/application-workspaces.md`
> 来源：原记于 `docs/todo.md` 的 T86 行，2026-09-19 迁入本文件，细节以本文件为准。
> 关联：T87（承接同一张卡的下一轮重设计）。

## 一、问题

实窗里标准档武器卡 233px、同宽护甲卡 133px，卡上三处空白没人用：

- 状态单独占一行（位置十几像素，右侧约 236px 全空）；
- 按钮行左侧空 138.8px；
- 来源面板备了 3 条的位置而多数武器没有 3 个来源（列表区实测用 34/53）。

## 二、改法（已改完）

1. 来源面板从 3 条收到 2 条，标题仍写全量条数与「另有 n 个」，详情全量不变；
2. 位置 / 锻造 / 整理状态 / 锁定与配装引用跟快捷操作按钮并成卡片底部一行，
   状态占左侧剩余宽度、按钮靠右；
3. 图标 `52px → 44px`，卡片固定高度按密度改成 `184 / 172 / 196px`，主区改成两行网格
   （主区 `1fr` + 底部行 `auto`）——原先主区按内容长，余量堆在按钮下面，同排卡片的按钮不在同一条线上；
   来源行数少的余量现在留成卡片底色，不摊成空的面板底色；
4. 删掉「按工作区容器宽度 ≤1020px 把事实行拆两列」那条覆盖：
   触发条件是窗户外层而卡片仍有 264px 起步，拆开反而让内容 34px 压进 22px 的轨道；
5. 事实行间距从 grid gap 改成子项 margin——没有勇士词条时第 4 列是空的，
   空列照样占一个 gap，光等会被挤到离右边缘 10px。

护甲与混合卡未动。

## 三、已知代价（已由 T87 消除）

武器名换两行且有 2 个来源时，来源面板被压到 48～54px，第二条来源底部裁掉几个像素
（面板自身 `overflow: hidden`，压不到按钮）。
