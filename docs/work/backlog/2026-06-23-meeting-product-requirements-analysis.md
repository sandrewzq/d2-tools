# 会议产品需求重组分析

## 背景

本次会议把后续方向从零散功能点重新收敛为几个产品主线：首页日常信息、全局 AI / 任务助手、账号与仓库体验、增强愿望单，以及 AI 辅助配装。会议里同时出现了一些数据来源不明确的内容，例如“今日轮换”“撒哈拉 / 周报”和 T1-T5 装备分层，这些不能直接写成实现承诺，需要先转为调研项。

本分析用于解释 `docs/todo.md` 的需求重组依据。当前短期待办仍以 `docs/todo.md` 为唯一入口。

## 会议结论

- 首页只承载每天打开后最需要看的信息：光等奖励进度、遗失区域、老九、枪匠、今日轮换、奖励等级和必要的数据来源状态。
- 任务助手不放首页，改为侧边栏或左侧导航能力。
- AI 助手移动到全局侧边栏，支持历史记录，并能在账号、仓库、配装等页面读取当前上下文。
- 账号页需要把角色做成一级切换入口，并补充货币、材料、邮政官等账号摘要。
- 仓库页参考 DIM 和 POE2 仓库页，转向更适合扫描和管理的卡片 / 平铺布局，并支持自定义标签。
- 装备详情页继续靠近游戏内展示方式，同时补模组加成数值和自定义标记入口。
- 增强愿望单需要支持用户自定义目标：武器指定 perk，护甲指定属性最低值，命中后自动标记或提示。
- AI 抄作业需要从攻略或用户资料中解析配装要求，对照账号数据给出匹配度、缺口、刷取建议，并生成可保存方案。

## 需求重组

### P0 · 首页日常信息与奖励进度工作台

首页从“综合入口”收敛为日常工作台。任务助手和 AI 长对话移出首页后，首页首屏应优先回答：今天有什么要看、哪些奖励快到、哪些商人或活动值得点开。

当前不能直接实现的部分先拆成调研项：

- “今日轮换”需要明确到底包含每日活动、每周轮换、商人库存、奖励重置，还是第三方整理口径。
- “撒哈拉 / 周报”需要确认数据来源，不能在 Bungie API 或外部来源不清楚时猜测展示。
- 遗失区域继续沿用“只展示可确认数据”的规则，不用泛关键词兜底。

### P0 · 全局 AI 助手与任务助手侧边栏

AI 和任务助手从页面内容变成跨页面能力。合理形态是全局侧边栏：主工作区继续展示账号、仓库或配装内容，侧边栏根据当前页面上下文提供问答、任务文本、攻略树和历史记录。

历史记录的具体承载方式还没有定论，可在侧边栏内二级面板、弹出抽屉和独立历史面板之间比较，但短期目标是先保证可查看、可恢复、可清理。

### P1 · 账号与仓库页面 UI / UX 重构

账号页的重点从“列出角色数据”升级为“围绕当前角色组织账号信息”。角色应作为一级入口，角色装备、背包、货币和材料摘要跟随切换。

仓库页要服务更高频的扫描、保留和筛选。自定义标签应成为仓库管理的基础能力，后续可以和增强愿望单、详情页标记、同名对比和自动配装联动。

装备筛选里的套装筛选和 T1-T5 暂不直接实现，需要先弄清楚它们是游戏字段、社区约定，还是本地用户定义。

### P1 · 增强愿望单与目标刷取标记

增强愿望单不应只等同于社区 wishlist 导入，而是本地目标规则系统：

- 武器目标：用户指定 perk 或 perk 组合，刷到后显示命中。
- 护甲目标：用户指定任意数量的新六维最低值条件，刷到后显示命中。
- 命中动作：可配置为只提示、自动加标签，或在明确授权后执行收藏 / 锁定类写操作。

这个方向可以承接旧社区推荐重做，也可以复用已经实现的护甲属性筛选模型。

### P1 · AI 抄作业与自动配装方案生成

AI 抄作业的核心不是普通聊天，而是把攻略内容转成结构化配装需求，再和账号数据做匹配。输出至少需要包含：

- 攻略要求：职业、子职业、星象 / 碎片、异域、武器、模组、属性目标和关键循环。
- 匹配度：已有、缺失、可替代、属性不足、需要升级、需要刷取。
- 方案结果：推荐装备组合、替代方案、缺口清单、刷取建议和可保存的本地方案草稿。

该能力依赖账号数据、仓库目标规则和配装模板，适合拆成多阶段实现。

## 优先级

P0：

- 首页日常信息与奖励进度工作台。
- 全局 AI 助手与任务助手侧边栏。

P1：

- 账号与仓库页面 UI / UX 重构。
- 增强愿望单与目标刷取标记。
- AI 抄作业与自动配装方案生成。

P2：

- 装备详情游戏内风格 UI 收尾，包括模组加成和自定义标记。

长期或暂缓：

- 完整 DIM 级拖拽装备移动。
- 完整护甲属性优化器。
- Raid Report / Destiny Tracker 级深度复盘和排行榜。
- 公网分享、多用户服务和图片化报告发布。

## 不确定项

- “今日轮换”的产品边界和数据来源。
- “撒哈拉 / 周报”具体指向，以及是否存在稳定可用的数据源。
- T1-T5 装备分层的语义和来源。
- AI 历史记录是侧边栏内面板、弹出抽屉，还是独立页面。
- 自动标记收藏、锁定或标签写入的默认安全策略。
- AI 抄作业首版是否只支持用户粘贴文本，还是同时支持链接摘要。
