# 路线图

更新日期：2026-06-20

这份文档只记录后续规划，不重复当前功能状态。当前做到哪了请看 [项目状态](project-status.md)。

## 当前阶段

`0.0.4` 是公开测试基线。

这个阶段的重点是先让普通 Windows 玩家稳定完成：

- Bungie 配置和登录
- 账号与仓库读取
- 本地资料库搜索
- 基础 DIM 风格整理
- 今日 / 本周浏览
- AI 分析
- 有边界的写操作

## 1. 仓库整理体验

目标：继续向 DIM 的高频整理体验靠近，但保持 d2-tools 的本地图形化风格。

近期方向：

- 更强的重复组对比视图
- 更顺手的低分候选批量处理
- 更清楚的游戏内定位信息
- 愿望单和本地评分协作增强
- 护甲属性组合建议增强

## 2. 今日 / 本周信息

目标：把今日 / 本周面板做得更像玩家每天会看的摘要，而不是一堆零散字段。

近期方向：

- 更稳定的商人库存显示
- 更完整的遗失区域信息
- 更清楚的本周活动线索
- 更接近中文日报 / 周报的呈现方式
- 继续坚持“只显示可确认数据”

## 3. AI 助手

目标：让 AI 成为“能读懂当前账号数据的助手”，而不是固定模板生成器。

近期方向：

- 更自然的账号数据问答
- 和今日 / 本周摘要联动的建议
- 更细的仓库清理建议
- 更明确的操作提醒和安全边界
- 更好的上下文组织和结果结构

## 4. 活动与复盘

目标：补齐 Raid Report / Destiny Tracker 方向的基础复盘能力。

近期方向：

- Raid / Dungeon 记录增强
- 最近活动摘要增强
- 小队进度本地对比
- 更可读的复盘摘要

## 5. 桌面体验

目标：继续降低普通玩家的使用门槛。

近期方向：

- 更明确的状态提示和错误反馈
- 包体与安装体验评估
- 自动更新评估
- 本地备份 / 恢复能力评估
- 更完整的诊断信息

## 6. 高级接口方向

目标：保留高级扩展能力，但不改变普通玩家“双击 exe 使用”的主入口。

近期方向：

- HTTP API 的 GUI 开关
- 更完整的本地工具 handler
- MCP server 可行性评估
- 工具调用审计增强

## 长期不做

- 在公开包里内置 Bungie 密钥
- 默认暴露公网服务
- 让 AI 自动执行写操作
- 直接分解装备
- 展示无法确认的数据
- 多人共享链接或图片化报告发布
