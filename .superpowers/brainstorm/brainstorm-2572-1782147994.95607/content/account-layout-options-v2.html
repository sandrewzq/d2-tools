账号页重构方向

这次不讨论“拉宽一点会不会好”，只讨论信息结构。目标是缩短主滚动链路，让高频任务首屏就能做，低频信息退到侧边或二级区。

推荐方案

A. 工作台型

保留单页，但把主流程和辅助信息拆成并行结构。

账号摘要 / 角色切换 / 快捷操作
当前角色装备 首屏核心区，打开账号页第一眼就能看装备与背包。
方案库 / 转移计划 / DIM 工具 把“下一步要处理的操作”集中在主列，不再和材料、活动混在一起。
材料与消耗品 顺手扫一眼
邮政官 异常提醒优先
最近活动 低频信息
本地模板 附属入口

为什么推荐

  • 最直接解决“信息流太长”，不是假装靠宽度掩盖问题。
  • 高频任务集中在主列，低频块缩到侧栏，首屏密度更合理。
  • 对现有代码侵入相对可控，不需要把业务硬拆成很多新页面。

备选方案

B. 分区型

把账号页切成“装备 / 配装 / 资源 / 活动”几个二级区。

账号摘要 / 角色切换
装备 配装 资源 活动
当前分段内容主体 一次只看一件事，页面会更短，但频繁切换模块时成本更高。

优点是最短，缺点是被拆散以后，账号页会从“工作台”变成“多页切换器”。

保守方案

C. 折叠型

保留长页，只把次要块默认折叠起来。

账号摘要 / 角色切换
当前角色装备 默认展开
DIM 工具 默认展开
方案库 可折叠
材料 / 邮政官 / 活动 折叠后隐藏

改动最小，但本质还是长页，只是把问题叠起来，不算真正解决。
