# 2026-07-16 项目分析

## 项目概况
- **名称**: d2-tools（原名 d2-service）
- **定位**: 面向中文玩家的 Windows Destiny 2 桌面工具
- **版本**: 0.0.13
- **技术栈**: Node.js 22 + pnpm 9 + TypeScript + Electron + React + Vitest
- **仓库**: github.com/sandrewzq/d2-tools，MIT 开源
- **当前分支**: codex/phase-0-local-gui-bootstrap

## 架构
- 8 包 monorepo: core(117) / desktop(154) / app(39) / ui(38) / services(21) / prototype(3) / web(4) / http(1)
- 分层: core → services → app → ui/product host → 平台壳(desktop/web/prototype)
- Desktop feature 目录: account/ai/daily/home/library/loadouts/settings/vault/vendors
- 核心能力: 账号查看、仓库整理、资料库搜索、今日/本周、AI 助手、配装、商人

## 当前状态
- 5 个进行中任务(T1-T5): 攻略解析、仓库推荐、商人结构、活动复盘、装备详情
- CI: GitHub Actions 异步执行 frozen install + test + typecheck
- Release: tools/git-auto-release.cmd 完整门禁
- Agent 默认不自动运行验证
